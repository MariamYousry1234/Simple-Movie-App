# Memory Game

**Memory Game** is a simple C# Windows Forms application where players try to match pairs of hidden images.

## Features
- Randomly distributes image pairs on buttons.
- Players click buttons to reveal images.
- Matching images stay revealed, non-matching flip back.
- Counts the number of moves.
- Option to restart the game and play again.
- Simple and intuitive UI.

## Technologies
- C#
- Windows Forms
- Async/await for smooth image flipping

## How to Play
1. Run the application.
2. Click on a button to reveal the hidden image.
3. Click a second button to try to find the matching pair.
4. If the images match, they stay revealed.
5. If all pairs are matched, the game shows your total moves and offers a restart option.
